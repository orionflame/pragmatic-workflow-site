Live GPU field analysis

GPU-Native Volume Analysis

Analyze fields directly in the viewport, without creating analysis nodes.

Explore interactive slices, voxel-center inspection, curl, divergence, vector fields, streamlines, vector trails and vector or strain-rate tensor representations.

Temporary analysis and visualization stay on the GPU with no result readback to the CPU. Source volumes still follow normal Houdini evaluation when their underlying data changes.

GPU-native computations Interactive slicing Curl & divergence Vector trails Tensor glyphs No additional SOP nodes

In development · GPU viewport comparison

GPU-Native Viewport Compare

Compositor-grade A/B comparison for all supported geometry types.

Compare arbitrary geometry, volumetric and simulation results directly in Houdini's 3D viewport with interactive wipes, source isolation and stacked views.

A GPU-native comparison path provides visual modes such as Difference and Onion Skin without comparison SOP nodes or CPU readback. Difference is based on viewport appearance, not numerical geometry metrics.

A / B sources Interactive wipe Geometry & volumes Simulation results Difference Onion Skin

FAQ

Before you install.

Which Houdini versions and operating systems are supported?

Supported Houdini versions and operating systems will be published with the verified release before purchases open.

What is included with Workflow?

Workflow combines advanced parameter editing, IDE-grade development, GPU-native volume analysis, graph diagnostics, network navigation and supporting productivity systems. GPU-Native Viewport Compare is in development and is not part of the current release. Features included in a purchase depend on the verified build; Pragmatic Operators is a separate product.

How does licensing work?

Individual licenses are assigned to one named customer, support one concurrent seat and up to two activated devices, and include 12 months of update coverage. Workflow is $199 Indie / $399 FX in year one, with $169 / $329 active renewal pricing. Eligible releases remain usable permanently. Studio licensing uses a floating concurrent seat pool sized to the purchased tier.

Can I customize the interface?

Yes. Verified options include density and layout, supported interaction preferences, overlay behavior, timeline interaction, Resource Monitor presentation, and other component-specific UI preferences. Available options vary by component.

How is Workflow different from Suite?

Workflow is the workspace and productivity product. Pragmatic Suite combines Workflow with Pragmatic Operators under the broader bundle offer. Operators is not included in a standalone Workflow license.
